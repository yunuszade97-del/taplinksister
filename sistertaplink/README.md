# Шафаг Садыгова — визитка врача-гастроэнтеролога

Одностраничная визитка для taplink. Врач-гастроэнтеролог, диетолог, Санкт-Петербург.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Готовая страница. Один файл, инлайн CSS/JS, внешних зависимостей нет кроме Google Fonts. Это то, что публикуется. |
| `photo.jpg` | Портрет врача |
| `Гастроэнтеролог - визитка.dc.html` | Редактируемая версия для дизайн-правок (нужны `support.js` и `_ds/`) |

## Публикация

Открыть `index.html` в браузере — работает как есть. Для taplink: вставить содержимое в блок «HTML-код», фото загрузить отдельно и подставить его URL в `<img id="doc-photo">`.

## Что осталось заполнить

Чек-лист в комментарии в начале `index.html`. Кратко:

- ссылка на Instagram (сейчас плейсхолдер)
- ссылка на отзывы (сейчас prodoctorov.ru)
- категория врача — если есть, добавить блок в `.stats`
- юрлицо / лицензия в footer, если требует клиника

## Стек

Чистый HTML + CSS. Анимации — CSS transitions + IntersectionObserver, с поддержкой `prefers-reduced-motion`. Дизайн-система Organic (тёплая палитра), шрифты Podkova + Manrope.
